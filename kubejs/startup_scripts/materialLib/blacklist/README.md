## Blacklisting
### Adding an entry to the blacklist
Blacklisting is probably the simplest process in the entire materiallib process.
All you need to do is create an entry, and add items per component to it.

Here is a working example that adds blacklisting for mekanism copper components:
```js
BlacklistHandler.getMaterial('copper')
    .setItems([
        {component: 'dust', items: ['immersiveengineering:dust_copper']},
        {component: 'nugget', items: ['immersiveengineering:nugget_copper']},
        {component: 'plate', items: ['immersiveengineering:plate_copper']},
        {component: 'wire', items: ['immersiveengineering:wire_copper']}
    ])
    .register();
```
As you can see, we first run `.getMaterial()` to indicate what material we are adding to the blacklist.

After that we use `.setItems()` to push an array of entry objects for blacklisting.

An entry object has an identifier for the component, and an array with item ID's

The builder automatically checks whether there already exists a blacklist for your material, and if so, loads it, and adds the new data to it.

It is recommended to place blacklists for separate mods in separate files, with a `// requires:<modid>` at the top of the script.
This way you can have a bunch of blacklists just sitting in your folders, and they will only trigger if the mod they work with is loaded.

### Blacklist functionality
All items on the blacklist are processed on the server and client side.

If an item blacklist is found for a material, or a component of that material, that is not generated by MaterialLib, the blacklist will skip that item.

All recipes using the blacklisted items* will have the item replaced by their MaterialLib counterpart.
Blacklisting is also automatically applied to all tags, meaning any recipe using a `#c:<component>/<material>` tag will have that replaced by the MaterialLib item, again on the premise that the item exists.

*Some mods use recipes that are not datadriven/are hardcoded. This means that those recipes sadly can't be altered easily.
